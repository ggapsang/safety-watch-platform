# 플러그인 만들기

이 문서가 **계약**입니다. 코드가 아니라 이 문서가 기준입니다.

`modules/_sdk/` 는 이 계약의 파이썬 편의 구현일 뿐입니다. 다른 언어로 만들어도 되고,
그때는 이 문서만 지키면 됩니다. SDK 를 쓴다고 특권 통로가 생기지 않습니다.

---

## 0. 플러그인이란 무엇인가

**코어가 그 존재를 모르는 채로 붙었다 떨어지는 것**입니다.

`server/` 어디에도 `yolo` 라는 단어가 없습니다. 객체감지 플러그인을 지워도 코어는
그대로 돕니다. 새 플러그인을 붙일 때 코어를 고쳐야 한다면 그것은 플러그인이 아닙니다.

이 기준은 실제로 지켜야 하는 것입니다. 구현하다가 "코어에 이것만 추가하면 되는데" 라는
생각이 들면, 대개 계약을 잘못 읽은 것입니다. 먼저 물어봐 주십시오.

---

## 1. 플러그인이 할 일 — 네 가지

### 1.1 등록

```
POST /api/modules
{
  "id": "collision",                  필수. 영문·숫자·하이픈. 이 값이 평생 이름이다
  "name": "충돌 위험",                화면에 보일 이름
  "kind": "sidecar",                  internal | sidecar | remote | edge
  "description": "AMR 과 사람의 접근을 본다",
  "capabilities": ["COLLISION"],      낼 수 있는 탐지 항목 코드들
  "endpoint": "http://localhost:12010"  자기 화면 주소. 없으면 빈 문자열
}
```

같은 `id` 로 다시 부르면 **갱신**입니다. 플러그인이 재시작할 때마다 실패하면 안 되므로
그렇게 만들어 두었습니다.

`kind` 는 어디서 도는지입니다. 코어는 이 값으로 아무 동작도 바꾸지 않고, 화면에만
씁니다 — 어디서 돌든 계약이 같다는 것이 요점입니다.

`endpoint` 를 주면 플랫폼 사이드바 **플러그인** 그룹에 탭이 생기고 그 주소를 iframe
으로 감쌉니다. **브라우저가 닿는 주소**여야 합니다. 컨테이너 이름(`http://mod-x:8000`)을
적으면 서버에서는 되는데 화면에서는 안 됩니다.

### 1.2 일감 받기

```
GET /api/modules/{id}/work
->
{"module_id": "collision", "items": [
  {"camera_id": 1, "camera_name": "...", "location": "...",
   "rtsp": "rtsp://base-media:8554/cam/1",
   "rtsp_sub": "",                               저화질. 없으면 빈 문자열
   "snapshot": "/api/stream/1/snapshot.jpg",
   "options": {}}
]}
```

**어느 카메라를 담당하는지**를 묻는 곳입니다. 할당은 사람이 플랫폼 관리자 화면에서
합니다 — 플러그인이 스스로 정하지 않습니다.

주기적으로(기본 20초) 다시 물어야 합니다. 할당이 늘거나 줄면 따라가야 합니다.

빈 목록이 정상입니다. 아직 아무도 할당하지 않았다는 뜻이고, 그때는 조용히 기다립니다.

> **영상을 안 쓰는 플러그인도 이 API 를 씁니다.** 규칙만 따지는 플러그인은 `rtsp` 를
> 무시하고 `camera_id` 만 쓰면 됩니다. "어느 카메라를 담당하나"는 똑같은 질문입니다.

### 1.3 발행

**판정 결과를 REST 로 돌려주지 않습니다.** MQTT 로 냅니다.

```
토픽   aivision/detect/{camera_id}/{module_id}
{
  "camera_id": 1,
  "module_id": "collision",
  "item": "COLLISION",          플랫폼 탐지 항목 코드
  "state": "active",            active | inactive
  "ts": "2026-09-14T01:23:45Z",
  "confidence": 0.87,
  "boxes": [ ... ]
}
```

```
토픽   aivision/live/{camera_id}
{
  "camera_id": 1,
  "module_id": "collision",
  "ts": "2026-09-14T01:23:45Z",
  "boxes": [ ... ]
}
```

둘의 성격이 다릅니다. **이 구분이 계약에서 가장 중요합니다.**

| | `detect` | `live` |
|---|---|---|
| 언제 | **상태가 바뀌는 순간만** | 매 프레임 |
| 적재 | 이벤트로 DB 에 쌓임 | 쌓이지 않음. 화면에만 |
| 빈도 | 드물다 | 초당 여러 번 |

`live` 를 `detect` 로 내면 **DB 가 무너집니다.** 사람이 서 있는 동안 초당 세 번
"사람 있음"을 이벤트로 쌓으면 하루에 수십만 건이 됩니다. 계속 보이는 동안은 아무것도
내지 말고, **안 보이다가 보일 때**와 **보이다가 안 보일 때**만 내십시오.

전이 판정이 귀찮으면 SDK 의 `Debouncer` 가 해 줍니다.

### 1.4 생존 신고

```
POST /api/modules/{id}/heartbeat
{ 아무 모양이나. 그대로 보관되어 화면에 보인다 }
```

기본 30초. 90초 넘게 없으면 화면에 '응답 없음'으로 보입니다.

## 2. 박스의 모양 — 어기면 안 되는 것

```json
{"x1": 0.12, "y1": 0.34, "x2": 0.56, "y2": 0.78, "label": "사람", "score": 0.91}
```

- **좌표는 0~1 정규화입니다.** 픽셀로 보내지 마십시오. 프레임 크기는 스트림 프로파일에
  따라 바뀌고, 그것을 아는 쪽은 **보내는 쪽**입니다. 받는 쪽은 모릅니다.
- `x1 < x2`, `y1 < y2`. 왼쪽 위가 (0,0) 입니다.
- `score` 는 0~1. 없으면 생략해도 되지만, 있으면 화면과 필터가 씁니다.
- `label` 은 **사람이 읽을 이름**입니다. 항목 코드(`ITEM-001`)를 넣지 마십시오 —
  이벤트 상세창에 그대로 그려집니다.

## 3. 남이 낸 판독을 받아 쓰기

`aivision/live/{camera_id}` 는 **공개 토픽**입니다. 코어만 읽으라고 만든 것이 아닙니다.

규칙을 따지는 플러그인은 영상을 다시 열지 말고 이미 나와 있는 박스를 받아 쓰는 편이
낫습니다. 같은 프레임을 두 번 추론할 이유가 없고, 사람처럼 카메라가 이미 잘 잡는 것을
다시 학습할 이유도 없습니다.

```python
from _sdk import LiveSubscriber

sub = LiveSubscriber(cfg.mqtt_host, cfg.mqtt_port, "collision")
sub.on_boxes(lambda f: store(f))          # f.camera_id, f.module_id, f.boxes
sub.start(cameras=[1, 2], modules=["yolo-server", "camera-meta"])
```

지금 실제로 흐르고 있는 것(참고용이며, 현장마다 다릅니다):

```
aivision/live/2   module_id "camera-meta"   label "Human"           카메라 내장 분석
aivision/live/1   module_id "yolo-server"   label "자율주행로봇"     우리 ONNX 모델
```

### 주의할 점

**라벨은 고정된 코드가 아닙니다.** 화면에서 사람이 바꿀 수 있습니다. `"Human"` 을 코드에
박아 두면 누가 "사람"으로 고치는 순간 조용히 멈춥니다. **설정으로 받으십시오.**

**발행자를 가리십시오.** 같은 토픽에 여러 플러그인이 냅니다. `module_id` 로 거르지
않으면 자기가 낸 박스를 자기가 다시 먹습니다.

**받은 것을 믿지 마십시오.** 발행자는 다른 팀이 만든 것일 수 있습니다. 모양이 다르면
버리고 넘어가야 합니다 — 남의 버그로 내 플러그인이 죽으면 안 됩니다. `parse_frame()`
이 그 검사를 합니다.

**시각을 맞출 때는 도착 시각을 쓰십시오.** 발행자의 `ts` 는 그쪽 시계이고 지금은 초
단위까지만 적힙니다. 서로 다른 발행자의 판독을 짝지어야 한다면 `Frame.received`
(도착 시각)가 더 쓸 만합니다.

**콜백은 MQTT 스레드에서 불립니다.** 거기서 무거운 일을 하면 메시지가 밀립니다. 받은
것은 자기 자료구조에 넣고, 판정은 자기 스레드에서 하십시오.

## 4. 자기 화면 갖기

플러그인에 사람이 할 일이 있으면(설정·모델 관리 등) 화면을 **직접** 띄웁니다.
플랫폼 화면에 넣으면 코어가 그 플러그인을 알게 됩니다.

- 아무 웹서버나 됩니다. 코어는 `endpoint` 를 iframe 으로 감싸기만 합니다
- 설정 화면에 필요한 카메라 정보는 플랫폼 REST 에서 읽습니다
  - `GET /api/cameras` — 전체 목록(ip·이름·위치)
  - `GET /api/modules/{id}/work` — 자기에게 할당된 것만
  - `GET /api/solutions` — 탐지 항목 목록. 출력을 무엇에 연결할지 고르는 드롭다운용
  - `GET /api/stream/{camera_id}/snapshot.jpg` — 카메라 한 장. 영역을 그리는 UI 에 씁니다
- 플랫폼이 안 보여도 화면이 죽으면 안 됩니다. 빈 목록으로 내려앉으십시오

**설정은 플러그인이 알아서 보관합니다.** 코어에 저장하는 길은 없습니다 — 있으면
코어가 플러그인의 설정 모양을 알게 됩니다. 자기 볼륨에 파일로 두는 것이 가장 간단하고,
객체감지 플러그인의 `/models/module.json` 이 그 예입니다.

## 5. 붙이는 법

`deploy/docker-compose.yml` 에 서비스를 하나 추가합니다.

```yaml
  mod-collision:
    build:
      context: ../modules            # _sdk 를 같이 담으려면 컨텍스트가 modules/ 여야 한다
      dockerfile: collision/Dockerfile
    ports:
      - "${COLLISION_UI_PORT:-12010}:8000"
    restart: unless-stopped
    depends_on:
      base-app: { condition: service_started }
      base-broker: { condition: service_started }
    environment:
      PLATFORM_URL: http://base-app:8000
      MQTT_HOST: base-broker
      MQTT_PORT: "1883"
      MODULE_ID: collision
      MODULE_NAME: 충돌 위험
      PUBLIC_URL: ${COLLISION_PUBLIC_URL:-http://localhost:12010}
```

컨테이너 안에서는 `base-app`·`base-broker` 로 부릅니다. 브라우저가 보는 주소
(`PUBLIC_URL`)는 호스트 주소여야 합니다. 이 둘을 헷갈리는 것이 가장 흔한 실수입니다.

## 6. 붙이기 전 점검

```
[ ] 등록이 된다. 플랫폼 관리자 화면의 모듈 목록에 보인다
[ ] heartbeat 가 온다. '응답 없음' 이 아니다
[ ] 카메라를 할당하면 일감을 받아 간다. 할당을 빼면 멈춘다
[ ] 박스 좌표가 전부 0~1 이다
[ ] label 이 사람이 읽을 이름이다 (항목 코드가 아니다)
[ ] detect 를 전이 순간에만 낸다. 계속 보이는 동안 반복해 내지 않는다
[ ] 플랫폼을 내려도 플러그인이 죽지 않는다 (재연결을 기다린다)
[ ] 브로커를 내려도 플러그인이 죽지 않는다
[ ] endpoint 를 브라우저에서 직접 열면 화면이 뜬다
```

마지막 두 줄이 특히 중요합니다. 플랫폼과 브로커는 재시작합니다. 그때 플러그인이 죽으면
사람이 손으로 올려야 하고, 아무도 그 사실을 모릅니다.

## 7. 지금 없는 것 (기술 부채)

숨기지 않고 적어 둡니다. 외부에 배포하기 전에 해결해야 합니다.

- **인증·권한이 없습니다.** 플러그인이 `/api/*` 를 전부 부를 수 있습니다. 카메라
  접속 정보도 읽힙니다(비밀번호는 평문으로 저장됩니다). 사내망 전제이고, 토큰과
  스코프가 필요합니다
- **계약 버전이 없습니다.** 등록에 `contract_version` 이 없어서, 코어가 토픽이나 박스
  모양을 바꾸면 기존 플러그인이 조용히 깨집니다
- **적합성 테스트가 없습니다.** 위 6장 점검표를 자동으로 돌리는 스크립트가 있어야
  "우리 쪽에선 되는데요" 를 끝낼 수 있습니다
- **설치가 저장소 수정입니다.** compose 를 고쳐야 하므로, 외부 플러그인을 받으려면
  우리 저장소에 손이 들어갑니다
- **탐지 항목을 요구할 수 없습니다.** `capabilities` 는 선언일 뿐이라, 없는 항목을
  쓰려면 사람이 플랫폼에 먼저 만들어야 합니다
