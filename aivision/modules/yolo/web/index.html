객체감지 — 모델과 탐지 설정

이 화면은 모듈이 직접 띄웁니다. 플랫폼 코어는 여기에 무엇이 있는지 모릅니다 — 등록된 모듈의 주소를 탭으로 감싸 보여 주기만 합니다. 학습은 여기서 하지 않습니다. 학습한 모델을 ONNX 로 내보내 올리세요.

모델 올리기

ONNX 파일만 받습니다. 올리면 바로 열어 보고, 클래스 이름이 들어 있으면 읽어 아래 표를 채웁니다. 없으면 인덱스(0, 1, …)로 만들어 두니 이름은 직접 붙이세요.

추론 상태

플랫폼에서 이 모듈에 할당한 카메라를 처리하고 있는지 봅니다.

카메라상태

탐지 민감도

바꾸면 곧바로 저장되고 추론 워커가 새 값으로 다시 뜹니다(수십 초). 컨테이너를 다시 띄울 필요는 없습니다.

배치된 모델

쓸 모델을 고릅니다. 바꾸면 추론 워커가 새 모델로 다시 뜹니다.

모델크기클래스

탐지 대상

왼쪽은 모델이 들고 온 이름입니다. 이름이 없는 모델이면 인덱스가 그대로 나옵니다. 표시 이름은 대시보드 박스와 이벤트에 그려질 이름이고, 탐지 항목은 이벤트로 쌓을 때 쓸 플랫폼 항목입니다. 항목을 비워 두면 박스만 그리고 이벤트는 만들지 않습니다.
