이미지 판별률 평가

정답을 붙인 이미지 묶음(세트)을 객체감지 플러그인에 지금 켜 둔 공통 모델과 같은 민감도로 판독해, 정답과 비교합니다. 실시간 화면과 똑같이 판독하므로 여기서 나온 숫자가 관제 화면의 실력입니다.
일치 — 한 이미지의 정답 객체(AMR·Human)가 모두 같은 클래스로 IoU 0.5 이상 잡히고, 헛탐지가 없어야 합니다. 판별률 = 일치 / 데이터 × 100, 기준 95 % 이상.
세트는 데이터셋·라벨링 탭에서 '사용' 으로 고른 이미지로 만들거나, 폴더째 올립니다 (images/ + labels/(같은 이름의 YOLO txt) + classes.txt). 정답이 하나도 없으면 판독만 합니다.
