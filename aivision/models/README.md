# 객체감지 모듈이 쓰는 폴더입니다.

컨테이너 안에서는 `/models` 로 마운트됩니다.

- `*.onnx` — 추론에 쓸 모델. 모듈 화면(11990)에서 올리면 여기 쌓입니다. 파일을 직접
  넣어도 됩니다.
- `module.json` — 화면에서 고친 설정(적용 모델·클래스 이름·탐지 항목 연결·민감도).
  모델과 같은 곳에 두어 볼륨째 옮기면 설정도 따라갑니다. 손으로 고쳐도 되지만,
  모듈이 돌고 있으면 화면에서 저장할 때 덮어씁니다.

모델이 없으면 모듈은 dry-run(합성 박스)으로 내려앉습니다 — 배관을 확인하는 데는
지장이 없습니다.

학습은 이 모듈에서 하지 않습니다. GPU 워크스테이션에서 학습한 뒤 ONNX 로 내보내
올리세요. 학습 코드는 `refs/yolov7-training/` 에 있습니다.
